# Here we will know what each function in code do

1) get_documents_from_web(url)

purpose - Scraping the given url

Steps - 1. use WebBaseLoader to get text from url
        2. The RecursiveCharacterTextSplitter is used to split the content into smaller overlapping chunks of 
            size 400 characters, with 20 characters overlap.
        3. returns splitDocs

2) create_db(docs)

purpose - create a vector DB to store document embeddings for efficient retrieval

Steps - 1. The OpenAIEmbeddings model generates semantic embeddings for each chunk of text.
        2. The FAISS library is used to create a vector store with these embeddings.
        3. Returns the FAISS vector store, which allows similarity-based searches later.

3) create_chain(vectoreStore)

purpose - Build the chatbot chain, integrating a language model, document retriever, and prompts.

Steps - 1. use GPT model and set temparature
        2. ChatPromptTemplate is used to instruct model what to do
        3. FAISS vector DB is converted to retriever for getting (k=3) top 3 similar doc chunks
        4. Keeps track of previous convo in the chat for better understanding
        5. chain all of them together 

4) process_chat(chain,question,chat_history)

purpose - basically this is the chatbot
